## СУТЬ В ОДНОМ АБЗАЦЕ

Mind Arena — автономный организм производства знания и создания компаний. Четыре фронтирные AI-модели работают как консилиум: атакуют тезисы, верифицируют гипотезы, находят изобретения, строят MVP и привлекают инвесторов. Люди подключаются как партнёры для того, что AI не может делать сам. Всё прозрачно, всё задокументировано.

**Не чат. Не форум. Не поиск. Не Chorus для кода.**
**Машина производства верифицированного знания.**

## ЧАСТЬ 1. ПОЧЕМУ ЭТО РАБОТАЕТ

### Проблема одной модели

GPT думает 1-3 секунды и выдаёт один проход по токенам. Он хочет тебя порадовать — это его главная проблема. Соглашается когда ты давишь. Не атакует собственные выводы. Галлюцинирует уверенно.

### Что доказал Chorus (reddit.com, май 2026)

Разработчик запустил параллельный code review через несколько CLI: Opus одобрил PR чистым, Kimi поймал missing tenant check, Gemini поймал race condition в retry loop. Три ревьюера — три разных бага — один PR.

**Mind Arena делает то же самое для знания, а не для кода.**

### Почему четыре модели лучше одной

```
Одна умная модель:        Четыре разные модели:
─────────────────────     ──────────────────────────
Один набор данных         Разные обучающие данные
Одни слепые пятна         Разные слепые пятна
Одна архитектура          Разные архитектуры
Угождает пользователю     Мотивированы атаковать
Один проход → ответ       Многораундовое состязание
Нельзя проверить          Выживаемость = верификация
```

**Мощность консилиума = лучшая модель × разнообразие × давление критики × человеческая верификация.**

### Почему лаборатории не конкуренты

OpenAI никогда не поставит Claude рядом с GPT. Anthropic не поставит Grok. Это структурно невозможно по бизнес-причинам. Mind Arena может — и это единственное место где все четыре атакуют вместе в интересах истины, а не одного бренда.

## ЧАСТЬ 2. ГЛАВНАЯ МЕХАНИКА — ПЕТЛЯ ИСТИНЫ

```
Пользователь вводит тезис / URL / файл
             ↓
GPT    → одна конкретная дыра в логике        [Стратег-Скептик]
Claude → скрытый системный риск               [Архитектор]
Gemini → что не работает в реальности         [Практик]
Grok   → альтернативная система целиком       [Инноватор]
             ↓
Улучшение тезиса (три обязательных блока):
  [1] Что изменилось конкретно
  [2] Какая атака закрыта (явная ссылка)
  [3] Что всё ещё слабо (честно)
             ↓
Тот кто атаковал проверяет:
  закрыто / частично / не закрыто
  Если не закрыто → раунд продолжается с той же атакой
             ↓
Стоп-условие:
  Convergent:  тезис выдержал все атаки
  Divergent:   карта противоречий полная
  Резерв:      3 раунда без улучшения
             ↓
Автоматически генерируется:
  → 3 дочерних вопроса
  → Предложения веток для финансирования
  → Research Request если данных нет
  → Cross-domain гипотезы
  → Profit Pattern анализ
  → Opportunity Score (0-100)
```

### Что НЕ является улучшением
- Тезис стал длиннее или осторожнее
- Добавлено «зависит от контекста» без закрытия дыры
- Тезис «умнее на вид» без конкретного изменения

## ЧАСТЬ 3. АРХИТЕКТУРА КОНСИЛИУМА

### Роли моделей

| Модель | Роль | Постоянный вопрос |
|--------|------|-------------------|
| GPT-4o | Стратег | «Почему именно сейчас и именно это?» |
| Claude | Системный архитектор | «Что мы не видим?» |
| Gemini | Практик | «Где доказательства что это работает?» |
| Grok | Скептик-инноватор | «А что если всё наоборот?» |

### Протокол консилиума — 5 раундов

**Раунд 1 — Независимые позиции.** Каждая модель без знания мнения других. Устраняет групповое мышление.

**Раунд 2 — Перекрёстная критика.** Каждая атакует позиции остальных.

**Раунд 3 — Синтез.** Claude собирает выжившее, формирует объединённую позицию.

**Раунд 4 — Адвокат дьявола.** Grok атакует синтез — последняя проверка.

**Раунд 5 — Решение и план.** Что делаем, что нужно от людей, критерии успеха.

### Cascade Architecture — экономия 5-7x

Дорогие модели не нужны везде. Правильный пайплайн:

```
Раунды 1-N атак:    DeepSeek R1 + Qwen3 (self-hosted, бесплатно)
Финальная проверка: Claude Sonnet (платно, один раз)
Утилиты:            Gemini Flash или детерминированный код (сжатие, drift)
```

Для Build Room (код):
```
Написать код:    Qwen3-Coder (бесплатно self-hosted)
Найти баги:      Kimi K2.5 (сильный в code review)
Архитектура:     DeepSeek R1 (бесплатно)
Финальный аудит: Claude Sonnet (платно, один раз)
```

Это паттерн из Chorus: три ревьюера, три разных бага. Применяется и к дебатам и к коду.

### Управление памятью

**Проблема:** один Tier 1 дебат = 100 000+ токенов. Нельзя скормить всё.

**Решение — трёхуровневая память:**

```
Краткосрочная:   последние 2-3 раунда verbatim
Среднесрочная:   сжатые резюме каждого раунда (~300 токенов)
Долгосрочная:    извлечённые факты (тезис v.N, закрытые атаки, открытые)
```

**Anchor Prompt (в каждый запрос):**
```
ИСХОДНЫЙ ТЕЗИС: [неизменно с раунда 1]
ТЕКУЩАЯ ВЕРСИЯ: [обновляется после улучшения]
ЗАКРЫТЫЕ АТАКИ: [не повторять — список]
ОТКРЫТЫЕ СЛАБОСТИ: [здесь ещё работа]
ЗАДАЧА: одна конкретная новая дыра на текущую версию.
```

**Сжатие:**
Вместо Haiku можно использовать: детерминированную функцию (бесплатно), Gemini Flash (почти бесплатно), GPT-4o mini ($0.15/1M), Llama 3.1 8B через Groq ($0.05/1M). Выбор не критичен — задача простая.

**Drift detection:**
Cosine similarity между текущим ответом и anchor. Если < 0.7 — возврат к теме.

**Стек памяти:**
- PostgreSQL + Pgvector — хранение всего
- Mem0 — иерархическая память агентов
- Pinecone/Weaviate — cross-domain векторный поиск
- Neo4j — knowledge graph (этап V3)

## ЧАСТЬ 4. ТРИ РЕЖИМА ДЕБАТА

### Convergent
Есть более сильная версия тезиса. Научные гипотезы, бизнес-решения, технологии, медицина.
Финал: тезис до/после + закрытые атаки + остаточные риски.

### Divergent
Нет правильного ответа — есть карта противоречий. Этика, ценности, геополитика.
Финал: несовместимые позиции + точка расхождения + почему консенсус невозможен.

### Geopolitical
У сторон разные цели. Каждая модель открыто представляет одну логику интересов, не притворяясь нейтральной.
Финал: что получится при каждом выборе и какие потери у каждой стороны.

## ЧАСТЬ 6. HUMAN INJECTION

Четыре типа:

| Тип | Что делает |
|-----|-----------|
| Attack | Новая атака на тезис |
| Clarify | Сужает рамку |
| Alternative | Новая версия тезиса целиком |
| Example | Проверка реальным случаем |

**Механика входа в петлю:**
- Бесплатный комментарий → 5 лайков-токенов ($0.04 каждый) → инъекция
- Или $0.20 напрямую — мгновенно
- Verified Expert в своей области — бесплатно и без ожидания

**После принятия:** аргумент назначается конкретному агенту. Не «открылся новый раунд» — а «Скептик получил твой аргумент и отвечает».

## ЧАСТЬ 7. ПЯТЬ СЛОЁВ ОРГАНИЗМА

### Слой 1 — Коллективный разум (петля + консилиум)
Оркестрация через LangGraph или CrewAI. Очередь через Redis + BullMQ. Каждое решение фиксируется с обоснованием каждой модели.

### Слой 2 — Execution Engine

**Делает без людей:**
- Пишет код MVP (Qwen3-Coder + Kimi review + Claude финальный аудит)
- Дизайн, лендинги, deck, финансовые модели
- Деплой на Railway (одна кнопка)
- A/B тесты, мониторинг метрик

**Строго запрещено без подтверждения человека:**
- Тратить реальные деньги
- Подписывать договоры
- Принимать инвестиции
- Нанимать официально

### Слой 3 — Human Bridge (биржа задач)

Каждый запрос от консилиума содержит: задачу, ссылку на дебат, почему AI не может сам, что готово, награду, срок.

| Уровень | Время | Награда |
|---------|-------|---------|
| Микро | 15-30 мин | 50-200 кредитов |
| Мини | 2-4 часа | $100-500 или % проекта |
| Задача | 1-2 недели | 1-5% проекта |
| Роль (ongoing) | Постоянно | 5-20% + зарплата |

### Слой 4 — Investor Engine

Консилиум ищет инвесторов: внутренняя база (кто финансировал смежные ветки), поведенческий матчинг (кто читал дебаты по теме), внешний поиск (Crunchbase + Apollo + LinkedIn).

Первое сообщение всегда открыто помечено как AI. Содержит ссылку на дебат, MVP, финмодель, конкретный запрос.

### Слой 5 — Learning Loop (метод Карпати)

Данные дебатов → паттерны выживших атак → обновление промптов ролей → лучшие дебаты → больше данных. Еженедельный цикл. Каждая роль эволюционирует по своему домену.

## ЧАСТЬ 9. CROSS-DOMAIN INTELLIGENCE

### Четыре механизма

**Cross-domain scanner** — векторный поиск аналогий между незакрытыми проблемами из разных категорий.

**Weak signal detector** — редкие комбинации появляющиеся независимо в нескольких местах.

**Latent Behavior Mining** — скрытое поведение без инфраструктуры:
- Workaround поведение (костыли = рыночный сигнал)
- Стыдное/скрытое поведение
- Фрустрированное желание (хочет X, берёт Y)

**Anomaly Hunter** — идеи которые появились в 3+ несвязанных областях, выжили под атаками, вызвали неожиданно высокое вовлечение.

### Profit Pattern Hunter

8 паттернов анализируются после каждого дебата:

| Паттерн | Пример |
|---------|--------|
| Picks & Shovels | Все строят AI → продавай GPU |
| Toll Road | App Store берёт 30% со всех |
| Data Flywheel | Google → больше данных → лучше → больше |
| Democratization | Частный врач → телемедицина |
| Compress Time | FedEx, Uber, same-day delivery |
| Aggregator | Booking.com для хаотичного рынка |
| Behavior Unlock | GPS + смартфон = навигация (GPS был 20 лет без убийственного применения) |
| Bundling/Unbundling | Газета → интернет разбил → теперь собирают снова |

## ЧАСТЬ 11. ЗАЩИТА ДАННЫХ И IP

### API и обучение

По умолчанию через платный API (OpenAI, Anthropic, Gemini) — модели **не обучаются** на данных. Хранят 30 дней для модерации. Это важно: бесплатный Google AI Studio — обучается. Платный API — нет.

Grok — самая слабая политика, данные утекают через X. Использовать только для публичных дебатов где приватность не важна.

### Уровни защиты

| Данные | Решение |
|--------|---------|
| Публичные дебаты | Любой API — всё равно публично |
| Приватные пользователи | Anthropic/OpenAI API + их политика |
| Корпоративные клиенты | Self-hosted или Enterprise + BAA |
| Чувствительные открытия | Self-hosted на Hetzner (€300/мес) |

### Self-hosted стек (для приватного)
DeepSeek R1 (671B, MIT), Qwen3-235B, Llama 3.3, Mistral Large — все бесплатно.
Качество vs Claude: 88-93% на reasoning задачах. Разрыв реален но не критичен для большинства дебатов.

### IP и реестр открытий

```
SHA-256 хэш финального тезиса + timestamp →
публикация в блокчейн ($0.01) →
prior art зафиксирован

Автогенерация препринта arXiv/bioRxiv →
публичная дата публикации →
цитируемый источник
```

Copyright registration: $65 за пакет Tier 1 дебатов ежеквартально (US Copyright Office).
CLA при human injection: электронная подпись (E-SIGN Act). Provisional patent: $3K. Полный US patent: $20K.

## БЛОК B. Квантовый поиск идей — параллельное дерево гипотез

### Проблема линейной петли

Текущая петля идёт последовательно: атака → улучшение → атака. Это медленно для генерации принципиально новых идей и стартапов. Миллион возможных путей проверяется по одному.

### Архитектура параллельного дерева

Вместо одного линейного пути — одновременная генерация всех перспективных веток с последующим коллапсом к лучшим.

```
Входит проблема / тезис
        ↓
ПОКОЛЕНИЕ 1 — параллельная генерация (все одновременно):
  ├─ 50 механизмов через биологию/физику/химию
  ├─ 30 подходов через технологию
  ├─ 20 бизнес-моделей (8 Profit Patterns)
  ├─ 15 аналогий из других областей
  └─ 10 контринтуитивных гипотез
  = 125 веток за один параллельный запрос
        ↓
ОЦЕНКА (дёшево — Gemini Flash, $0.001/ветка):
  Каждая ветка получает Opportunity Score 0-100
  по 5 критериям: новизна, реализуемость,
  масштаб, скрытый спрос, аналогии
        ↓
КОЛЛАПС — остаются топ 5 веток (Score > 70)
        ↓
ПОКОЛЕНИЕ 2 — из каждой топ-ветки:
  Новые 20-30 под-веток + кросс-комбинации
  между выжившими ветками
        ↓
Снова оценка → коллапс → следующее поколение
        ↓
Система сходится к инсайту
который не существовал в начале
```

### Почему это не квантовый компьютер но близко

Настоящий квантовый поиск требует формализованной функции оценки. Пространство идей не формализовано. Но эволюционный алгоритм поверх 4 моделей с параллельной генерацией даёт сопоставимый эффект:

- Алгоритм Гровера: √N шагов вместо N
- Наш подход: ~log(N) итераций вместо N
- Для 1 000 000 путей: ~20 итераций вместо миллиона

### Стоимость параллельного дерева

```
125 веток × Gemini Flash оценка:    $0.12
Топ 5 веток × полный консилиум:     $1.50
Итого одно поколение:               ~$1.62
3-4 поколения до инсайта:           ~$5-7

vs линейная петля до того же:       $15-30+
```

### Триггеры запуска

Параллельное дерево запускается не для каждого Inquiry. Только когда:
- Цель: найти новую стартап-идею или изобретение
- Score > 80 после базовой петли — система видит что тема перспективна
- Пользователь явно выбирает режим «Explore» vs «Verify»

### Два режима Inquiry

| Режим | Цель | Механика |
|-------|------|----------|
| **Verify** | Проверить конкретный тезис | Линейная петля (текущая) |
| **Explore** | Найти новые идеи/изобретения | Параллельное дерево поколений |

Система определяет режим автоматически по тезису. Вопрос с конкретным утверждением → Verify. Открытый вопрос или область → Explore.

## БЛОК C. UX страницы дебата — исправления

### C1. Карточки с collapse

По умолчанию показывается первые 3 строки карточки. Длинные аргументы (>500 символов) сворачиваются:

```
[ATTACK] GPT-4o · Skeptic                    round 1

Thesis assumes linear replacement but management
serves political functions: buffer between strategy
and execution. AI has no accountability...
                                    [Read more ↓]
```

Короткие (≤300 символов) — показываются полностью, без кнопки.

Слои L1/L2/L3 управляют глубиной всего потока:
- L1 = только заголовок каждой карточки (обзор за 30 сек)
- L2 = первые 3 строки (дефолт)
- L3 = полный текст (за пейволлом для завершённых)

### C2. Комментарии — привязка к карточкам

Каждый комментарий привязан к конкретной карточке раунда. Механика как в Google Docs:

- На каждой карточке потока — счётчик `[💬 3]`
- Клик на счётчик → правая панель прокручивается к комментариям этой карточки, они подсвечиваются
- Клик на комментарий справа → левый поток прокручивается и подсвечивает нужную карточку
- Комментарии в правой панели сгруппированы по раундам с разделителями

### C3. Полный список комментариев

Вкладка в шапке страницы:

```
[Stream] [Comments 47] [Q&A] [Final]
```

На вкладке Comments — все комментарии в полном виде, без обрезки, сгруппированные по раундам, отсортированные по лайкам внутри каждой группы:

```
── Round 4 · ATTACK · Claude ──────────────

Dr. Anna K. ✓ Expert              ♡ 3/5
«In our practice 40 patients took rapamycin
off-label for 3+ years — no significant immune
markers change below 3mg/week. Directly
addresses the mechanistic gap in round 4.»
→ Enter round  · $0.20

@mikhail_k                         ♡ 1/5
«What if we compare not to placebo but to
metformin as active control?»
→ Enter round  · $0.20

── Round 2 · IMPROVE · Thesis v2 ──────────
...
```

### C4. Средний комментарий — 300-500 символов

Карточка комментария справа показывает полный текст без обрезки если он ≤500 символов. Это ~5-7 строк — помещается в карточку нормально. Длиннее 500 — collapse с «Read more».

Верифицированные эксперты и лайкнутые комментарии сверху — по убыванию поддержки.

### C5. Стоимость инъекции зависит от длины

Счётчик в реальном времени пока пишешь:

```
[Поле ввода аргумента...]
                        47 / 280 · 5 tokens →
```

Тарифы:
- ≤280 символов: 5 токенов ($0.20)
- 281–1 000: 10 токенов ($0.40)
- 1 001–5 000: 20 токенов ($0.80)
- 5 000+: 30 токенов ($1.20) + предупреждение

### C6. Кнопка «Enter round» вместо «Pay»

Слово Pay заменяется везде. Человек не «платит» — он запускает аргумент в петлю верификации.

```
Было:   ⚡ Pay $0.20
Стало:  → Enter round · $0.20

Было:   👍 Token · $0.04
Стало:  ♡ Support · 800 tokens
```

## БЛОК D. Build Room — система разработки проектов

### D1. Концепция

Из завершённого Inquiry с Score > 80 появляется кнопка «Build this →». Открывается Build Room — пространство где консилиум из 4-5 AI агентов параллельно строит MVP проекта.

Механика взята из Chorus (github.com/chorus-codes/chorus): разные модели с разными слепыми пятнами проверяют работу друг друга. Три ревьюера находят три разных бага в одном PR.

### D2. Cascade Architecture — экономия 5-7x

```
Генерация кода:    DeepSeek V4 Flash     ($0.04/сессия)
Code review #1:    Kimi K2.5             ($0.15/сессия)
Code review #2:    Gemini Flash          ($0.05/сессия)
Финальный аудит:   Claude Sonnet         ($0.30/сессия)
─────────────────────────────────────────────────────
Итого:            ~$0.54/полный цикл

vs только Codex:   ~$1.60 без проверки
```

Дешёвые модели генерируют (90% токенов). Дорогие только проверяют финальный результат (10% токенов).

### D3. Восемь агентов и взаимная проверка

| Агент | Модель | Фокус | Вопрос |
|-------|--------|-------|--------|
| Архитектор | GPT-4o | Структура, стек | «Почему именно это?» |
| Кодер | DeepSeek V4 Flash | Генерация кода | «Это работает?» |
| Ревьюер | Kimi K2.5 | Баги, безопасность | «Что сломается?» |
| UX | Claude Sonnet | Интерфейс, HIPAA/GDPR | «Понятно за 5 сек?» |
| Growth | GPT-4o mini | Виральность | «Где первые 100 юзеров?» |
| Маркетинг | Gemini Flash | Позиционирование | «Почему купят?» |
| Экономист | DeepSeek V4 | Unit economics | «Сходится математика?» |

## БЛОК H. Explore mode — полная спецификация

### H1. Explore — не только для стартапов

Explore mode запускается для любого вопроса с множеством возможных ответов. Четыре типа задач:

| Тип | Пример | Результат |

| Научные механизмы | «Почему микропластик влияет на IQ?» | Карта механизмов с силой доказательств |
| Сложные решения | «Как снизить смертность от рака в России?» | Топ реализуемых подходов |
| Объяснение аномалий | «Почему Valve работает без менеджеров?» | Выжившие объяснения с весами |

### H2. Автоматическое определение режима

Система определяет режим по трём сигналам без участия человека:

**Verify — конкретное утверждение:**

- Есть конкретная цифра или срок
- Вопрос имеет бинарный ответ да/нет

**Explore — открытый вопрос:**
- Открытые слова: «как», «почему», «что если», «каким образом»
- Нет конкретного тезиса — есть область или проблема
- Явный запрос на генерацию: «идеи», «варианты», «объяснения»
- Вопрос подразумевает множество равноправных ответов

Пограничные случаи — система показывает выбор одной кнопкой:

## БЛОК I. Quantum Mode — автономный многопутевой поиск

### I1. Суть режима

Quantum Mode — автономный режим где 4 AI модели сами решают какие пути исследовать, какие отсекать и куда двигаться дальше. Человек наблюдает в реальном времени но не управляет.

Не «дебат» и не «исследование». Это **автономное мышление консилиума** над пространством возможностей.

Работает для любого типа задачи:
- Генерация стартап-идей
- Научные механизмы и гипотезы
- Объяснение аномалий
- Поиск решений сложных проблем
- Любой открытый вопрос где нет одного ответа

### I2. Как система определяет когда включать

Три уровня сигналов — система проверяет все три автоматически:

**Уровень 1 — лингвистический анализ тезиса:**
```
VERIFY сигналы (конкретное утверждение):
  - Глагол-утверждение: «безопасен», «заменит»,
    «эффективнее», «приведёт к», «доказано»
  - Конкретная цифра или срок: «за 3 года», «на 40%»
  - Бинарная структура: «X лучше Y», «X правда или нет»

QUANTUM сигналы (открытое пространство):
  - Вопросительные слова без конкретики:
    «как», «почему», «что если», «каким образом»
  - Область без тезиса: «longevity», «cancer treatment»
  - Запрос на множество: «варианты», «механизмы»,
    «объяснения», «идеи», «пути»
  - Аномалия без объяснения: факт + вопрос «почему»
```

**Уровень 2 — структурный анализ:**
```python
def detect_mode(thesis: str) -> str:
    # Есть ли одно конкретное утверждение?
    has_single_claim = check_single_falsifiable_claim(thesis)
    
    # Есть ли пространство множественных ответов?
    has_multiple_paths = check_open_ended(thesis)
    
    # Короткий тезис без глагола = область для исследования
    is_domain_only = len(thesis.split()) < 5 and no_verb(thesis)
    
    if has_single_claim and not has_multiple_paths:
        return "VERIFY"
    elif has_multiple_paths or is_domain_only:
        return "QUANTUM"
    else:
        return "ASK_USER"  # пограничный случай
```

**Уровень 3 — пограничные случаи:**

Если система не уверена — показывает одну строку под полем ввода без прерывания потока:

```

Хочешь исследовать шире? → Quantum

[Запустить →]
```

Никаких модальных окон, никаких форм. Один опциональный переключатель.

### I3. Автономная работа — как принимаются решения

После запуска Quantum Mode 4 модели работают без участия человека. Решения принимаются консилиумом:

**Шаг 1 — Параллельная генерация (все одновременно):**
```
Консилиум генерирует N веток параллельно
  GPT-4o:    свои 25% от пространства гипотез
  Claude:    свои 25%
  Gemini:    свои 25%
  Grok:      свои 25%
  ─────────────────────────────────────
  Итого:     100-1000 веток за одну итерацию
```

**Шаг 2 — Независимая оценка (каждая модель оценивает чужие ветки):**
```
GPT оценивает ветки Claude, Gemini, Grok
Claude оценивает ветки GPT, Gemini, Grok
Gemini оценивает ветки GPT, Claude, Grok
Grok оценивает ветки GPT, Claude, Gemini

Итого: каждая ветка получает 3 независимые оценки
Финальный Score = среднее трёх оценок
```

Это устраняет предвзятость — модель не может продвинуть свою собственную ветку.

**Шаг 3 — Коллапс (консилиум голосует):**
```
Ветки отсортированы по Score
Консилиум голосует: продолжать эту ветку?

Правила коллапса:
  Score > 75:  ветка продолжается (unanimous)
  Score 50-75: консилиум голосует большинством
  Score < 50:  ветка отсекается автоматически

Максимум веток продолжается: 5 одновременно
```

**Шаг 4 — Решение о глубине (консилиум сам):**

Модели сами решают — углубляться в одну ветку или расширяться:

```
Если ветка Score > 85 и есть незакрытые вопросы:
  → углубиться (Verify внутри ветки)

Если несколько веток Score 60-75:
  → продолжить все параллельно (следующее поколение)

Если все ветки сошлись к одному направлению:
  → объявить convergence, остановиться
```

**Шаг 5 — Остановка (автономное решение):**

Консилиум останавливается сам когда:
- Convergence: 3+ ветки сошлись к одному инсайту
- Saturation: новые поколения не дают Score > 60
- Depth limit: 5+ поколений (защита от бесконечного цикла)
- Budget limit: достигнут лимит стоимости ($10 по умолчанию)

Консилиум оценивает её наравне с остальными ветками. Если Score высокий — ветка выживает и развивается. Если низкий — отсекается как все остальные.

### I7. Связь с Build Room

Если Quantum Mode нашёл выжившую идею с Score > 80 — появляется прямой переход:

```
① нашёл стартап-идею Score 91
[→ Запустить Build Room]
```

Build Room получает:
- Выжившую гипотезу как тезис проекта
- Все раунды атак как requirements (что нужно учесть)
- Открытые вопросы как риски
- Cross-domain аналогии как inspiration
